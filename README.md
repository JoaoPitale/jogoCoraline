# Run, Coraline!

## Nomes dos alunos
- João Lucca
- Laura Vargas

## Identificação do tema
Jogo 2D/3D de fuga e desvio de obstáculos inspirado no filme *Coraline*, no qual a jogadora foge por um túnel entre mundos enquanto é perseguida pela mão gigante da "Outra Mãe". O jogo adapta livremente o clímax da história, contextualizando o restante do enredo por meio de trechos narrativos exibidos entre as fases.
